# Downloads e atualizações da Comando

Este repositório público distribui o instalador e as atualizações assinadas dos
painéis de simulador da Comando.

## Instalador para Windows

**[Abrir a versão estável mais recente](https://github.com/Comando-Cockpit-Hardware/comando-releases/releases/latest)**

No release mais recente, baixe o arquivo `Comando-Installer-*-Windows.exe`.
O executável ainda não possui assinatura Authenticode, portanto o Windows pode
mostrar um aviso do SmartScreen na primeira execução.

## Conteúdo publicado

- instalador Windows;
- firmware dos painéis;
- perfis para X-Plane e Microsoft Flight Simulator;
- plugins do X-Plane e módulos do MSFS;
- `manifest.json` assinado, usado pelo instalador para verificar e baixar
  atualizações com segurança.

Os arquivos da pasta `latest/` são um espelho do canal estável. O cliente não
precisa baixá-los manualmente: o Comando Driver Installer faz isso.

O código-fonte e a documentação técnica ficam no repositório
[Comando_Paineis](https://github.com/Comando-Cockpit-Hardware/Comando_Paineis).
